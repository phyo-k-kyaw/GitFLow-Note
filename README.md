There are two ways you can add the file to your git repo.
1.The first one is form the local to git hub.
-First, you have to go to the folder or files that you want to push to the git repo.
-Second, you have to initilize the file with the git int command.
-Third, you have to add the files and then, commit it with the git add and commit command.
-Fourth, you need to creat a empty repo in the git without any file (readme, ignore, etc).
-Last, you will see the code fo rthe pushing an existing repo, and copy and paste it in the bash or terminal.
2.The second one is cloning the file from the repo in the github.
-You will go to the directonary in the local file.
-You have to use git clone command and the copy code.
-After that, you have to do git ass, commit and push.
